# Research Logs

Cross-domain research belongs here when its primary question concerns the Production Skills family rather than one production discipline.

New domains first create a minimal target repository under the [current bootstrap process](../bootstrap/README.md). Their bootstrap specifications and later stage outputs belong in that target repository's `docs/research-logs/`, before the production scaffold is built.

Earlier domain bootstrap specifications already stored here are historical references. Preserve them and link to their owning repositories; do not automatically rewrite their stage history when family policy changes.

Once a domain repository exists, domain-specific implementation research, book selection and permission decisions, source-access records, book extraction, broader challenge research, professional-practice research, benchmarks, examples, Extension Pack research and project decisions belong in that repository and should be linked rather than copied here.

Consuming-project research always remains with the consuming project unless a genuinely reusable cross-domain finding is later extracted through the family abstraction process.
