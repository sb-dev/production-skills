# Research Logs

Cross-domain research belongs here when its primary question concerns the Production Skills family rather than one production discipline.

A temporary exception exists for **new-project bootstrap specifications** generated before an owning Production Skills repository is scaffolded. Those bootstrap specs live here because they are outputs of the central family bootstrap process and define how the future domain repository will be created.

Once a domain repository exists, domain-specific implementation research, professional-practice research, benchmarks, examples, Extension Pack research and project decisions belong in that repository and should be linked rather than copied here.

Consuming-project research always remains with the consuming project unless a genuinely reusable cross-domain finding is later extracted through the family abstraction process.
