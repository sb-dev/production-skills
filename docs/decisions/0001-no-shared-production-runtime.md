# Decision 0001 — No Shared Production Runtime at Bootstrap

**Status:** Accepted  
**Date:** 7 September 2026

## Decision

The central Production Skills repository will not provide a shared production runtime, universal workflow DSL, universal artefact model, provider router or Extension Pack interpreter.

## Reason

The mature Narrative, Music and Video projects demonstrate common production principles but materially different artefacts and workflows. The current evidence supports sharing contracts and principles, not execution machinery.

## Revisit when

At least two independent domain implementations experience the same concrete runtime problem and a shared implementation is demonstrably smaller and safer than duplicated domain-specific solutions.
