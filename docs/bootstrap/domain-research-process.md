# Domain Research Process

Use this process before specifying a new Production Skills project.

1. Define the production discipline and adjacent boundaries.
2. Identify authoritative practitioners, workflows and terminology.
3. Map cheap representations, commitment points, expensive production and review loops.
4. Catalogue recurring failures and how practitioners repair them.
5. Identify what is deterministic, generative, judgement-heavy or tool-dependent.
6. Separate durable production knowledge from provider-specific behaviour.
7. Compare findings with existing Production Skills only after the domain model is independently understood.
8. Record candidate shared abstractions as hypotheses until multiple-domain evidence exists.

Research output belongs in the domain repository unless it is primarily comparing several Production Skills domains or defining family architecture.
