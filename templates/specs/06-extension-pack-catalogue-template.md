**Status:** Draft

## Purpose

Describe the curated Extension Packs implemented or planned for this Production Skills project and the showcase used to demonstrate each one.

The pack contract remains owned by `05-<domain>-customisation-packs-spec.md` or its domain-equivalent filename.

## Catalogue rules

Every published pack should define:

```text
name / slug
intended use
production grammar
pack dimensions
core skills affected
what remains stable
precedence / conflicts
showcase
exact generation prompt
pack-aware evaluation
implementation / maturity status
```

A catalogue entry is not merely a style or genre label. It must represent materially different production behaviour.
